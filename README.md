# Site TSARI (gwanitsari.com)

Site des logiciels TSARI : TSARI GWANI, AGRICULTURE, ÉLEVAGE, AQUACULTURE, MARAÎCHAGE.
Pages statiques en français (racine), anglais (`en/`) et haoussa (`ha/`), sans dépendance.

- Ne pas modifier ces fichiers à la main : ils sont produits par le générateur (`site.mjs`, `textes.mjs`, `nouveautes.mjs`), conservé hors de ce dépôt.
- Le fichier `CNAME` (gwanitsari.com) sera ajouté quand le domaine sera relié dans OVH. Ne pas le supprimer ensuite.
- Téléchargements et mises à jour des logiciels : https://tamtui.github.io/TAMTUI-TELECHARGEMENTS/
